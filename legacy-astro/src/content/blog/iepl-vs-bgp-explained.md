## 什么是 IPLC / IEPL 专线？

**IPLC**（International Private Leased Circuit，国际点对点租用专线）和 **IEPL**（International Ethernet Private Line）是指企业级跨境物理点对点专线。

简单来说，它的数据传输无需经过公网防火墙的大流量审查拦截，而是走内网专有物理光纤过境：

```
[用户电脑] ➔ [国内中转节点 (深圳/上海)] ➔ ⚡【IPLC 内网专线过境】⚡ ➔ [跨境出口 (香港/东京)] ➔ [目标网站]
```

### IPLC 的三大核心优势

1. **绝对零丢包**：物理内网点对点，不受国际出口拥堵影响。
2. **极低延迟**：广州至香港物理延迟可低至 5-8ms，上海至东京延迟低至 25ms。
3. **高稳定性**：不受特殊时期网络波动影响。

## 什么是 BGP 隧道中转？

**BGP**（Border Gateway Protocol，边界网关协议）中转是指服务器入口接入了多家运营商（电信、联通、移动）的 BGP 线路，数据进入国内中转机房后，通过加密隧道转发至境外节点。

- **优势**：成本低于物理专线，速度快，适合绝大多数日常 4K 视频与网页浏览。
- **缺点**：在极端晚高峰时期，由于中转出口仍经过公网，可能出现轻微延迟上升。

## 总结与挑选建议

- 针对 **远程办公、AI 大模型交互、外盘交易、竞技游戏** 需求 ➔ 优先选择 **IPLC / IEPL 纯专线**；
- 针对 **日常追剧、大文件下载、常规上网** 需求 ➔ 选择 **BGP 多路中转** 即可获得极高性价比。
